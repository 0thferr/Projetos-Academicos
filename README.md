# 🖥️ Computação Gráfica e Algoritmos

Este repositório reúne **atividades e projetos acadêmicos** desenvolvidos durante a graduação em **Engenharia da Computação**.  
Ele contém implementações em diferentes linguagens (C, C++, Python, Dart/Flutter) voltadas para algoritmos, estruturas de dados e introdução à programação.

---

## 📂 Estrutura do Repositório

- **Algoritmo guloso**  
  Implementações de algoritmos usando abordagem gulosa.  
  📚 Disciplina: *Teoria da Computação & Complexidade de Algoritmos*  

- **App (Dart & Flutter)**  
  Pequena aplicação mobile construída em Flutter.  
  📚 Disciplina: *Desenvolvimento de Dispositivo*  

- **Atividade – Python**  
  Exercícios de lógica e programação usando Python.  
  📚 Disciplina: *Computação Gráfica*  

- **Atividades Avaliativas – Introdução a Python**  
  Conjunto de exercícios em Python, JavaScript e C.  

- **Copa do Mundo – C++**  
  Exercício prático de manipulação de dados em C++.  
  📚 Disciplina: *Introdução à Programação – C++*  

- **Jogo com Estrutura de Decisão & Loop**  
  Projeto simples em C++ usando estruturas condicionais e laços.  
  📚 Disciplina: *Estrutura de Dados*  

- **Média Vetor**  
  Cálculo de médias utilizando vetores.  
  📚 Disciplina: *Teoria da Computação & Complexidade de Algoritmos*
